# Synesis EA live results gallery

Add live MT5 account screenshots to `live-accounts/`. Every supported image in that folder is added to the website gallery automatically the next time the client is built.

Supported formats: `.jpg`, `.jpeg`, `.png`, and `.webp`. Use numbered filenames to control display order, such as `01-account.jpg`, `02-monthly-summary.png`, and `03-trade-history.webp`.

Only add genuine account screenshots. The page notes that past performance does not guarantee future results.
