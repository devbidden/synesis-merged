# Synesis EA results gallery

Add screenshots to one of these folders. Every supported image in each folder is added to its own gallery section automatically.

- `samples/` - general account samples
- `settings/` - settings samples
- `live-accounts/` - live account screenshots
- `customer-accounts/` - customer account screenshots
- `backtests/` - backtest screenshots

Supported formats: `.jpg`, `.jpeg`, `.png`, and `.webp`. Use numbered filenames to control display order, such as `01-account.jpg`, `02-monthly-summary.png`, and `03-trade-history.webp`.

Only add genuine account screenshots. The page notes that past performance does not guarantee future results.
